# Jiu-Jitsu ScoreBoard

ブラジリアン柔術（BJJ）の試合に特化した、シンプルで使いやすいスコアボードアプリです。
タブレット等の大画面での利用を想定しており、道場での練習試合から本格的なトーナメントまで幅広く活用できます。

## アプリの特徴
- **直感的な操作**: タップのみでポイント、アドバンテージ、ペナルティを簡単に管理可能
- **公式ルール対応**: IBJJF（国際ブラジリアン柔術連盟）のスコアシステムをベースに設計
- **見やすいタイマー**: 試合時間のカスタマイズや、開始・一時停止・リセットがスムーズ
