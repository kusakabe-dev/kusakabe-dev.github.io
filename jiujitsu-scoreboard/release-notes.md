# リリースノート

Jiu-Jitsu ScoreBoard のアップデート履歴です。

## v1.1.0 (2026-08-02)

ペナルティに関するスコア連動機能の追加を中心としたアップデートです。

### 機能追加・改善
- **ペナルティ（ルーチ）の自動連動機能**: ペナルティが入力され累積した際に、ルール（IBJJF準拠）に応じて自動的に相手選手へアドバンテージやポイントが付与されるようになりました。ペナルティ取り消し時にも正しく連動して取り消されます。
- **DQ（反則負け）時のタイマー自動停止**: 4回目のペナルティ（DQ）が入力された際に、試合タイマーが自動で一時停止（PAUSE）するようになりました。

## v1.0.0 (2026-07-22)

正式版の初回リリースです。

### 基本機能
- **IBJJFスコアリング対応**: IBJJF（国際ブラジリアン柔術連盟）の基本的なスコアリングシステムに対応しています。
- **直感的なスコア管理**: タップ操作でポイント、アドバンテージ、ペナルティを管理できます。
- **試合タイマー**: 試合時間のカスタマイズと、開始・一時停止・リセット操作が可能です。

### その他追加・変更点
- **アプリ内マニュアル表示**: アプリ内でユーザーマニュアルを閲覧できる機能を追加しました。
- **広告の表示**: アプリ内の一部画面に広告（AdMob）を表示するよう変更しました。
- **Target API更新**: Android API 36に対応しました。

### 修正
- ユーザーマニュアル参照先URLのドメイン構造変更に対応しました。
