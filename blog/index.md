# 勉強用ログ (Blog)

このディレクトリには、AIアシスタントとの技術的なやり取りや設計に関する考察を記録します。

## 記事執筆時の掟

- 勉強用メモなので対象読者はあくまでも自分。
- 但し、他人が読んである程度理解できるように書くこと。
  - 勉強メモとはいえ、それを読み返す未来の自分も他人とみなす。
- 記事を書く際は必ず、1次情報をリンク付きで明記すること。
- 記事の要約（結論や成果物）は冒頭に書く。
- 環境やバージョンに依存する話題の場合は、それらの情報を明記する。
- 未解決事項（わからなかったこと）や今後の課題も正直に残す。
- AIのプロンプトなど、出力に至った重要な背景は記事の末尾に補足として残す。
